# VRealm – VR Features Website

A responsive static website introducing virtual reality features and applications, built using HTML5 and CSS3.

## Pages
- Home: introduction and highlights.
- Features: immersive visuals, motion tracking, spatial audio and interaction.
- Applications: education, healthcare, gaming and architecture.
- Contact: project information.

## Features
- Dark technology-inspired design.
- Responsive navigation and page layouts.
- CSS-generated VR illustration (no image assets required).
- Semantic HTML and reusable CSS.

## Run locally
Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Technologies
HTML5, CSS3.
